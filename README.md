# Monzer App - الإصدار v17 Masterpiece (UI/UX & OTP Fixed)

تطبيق مدير الأعمال والماليات وقانون العمل المصري المحدث. تم إصلاح نظام كود التحقق (OTP) وتصميم الواجهة بأحدث معايير الرقي وراحة العين (Glassmorphism & Clean Material Design).

## طريقة التثبيت والاستخدام داخل الهاتف:
1. فك ضغط الملف `Monzer_App_v17_Masterpiece.zip` داخل هاتفك المحمول.
2. افتح ملف `index.html` في متصفح Google Chrome.
3. اضغط على خيارات المتصفح واختر "إضافة إلى الشاشة الرئيسية" لاستخدام التطبيق بلمسة واحدة.
